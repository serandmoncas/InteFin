Modelo de Datos — InteFin

Schema PostgreSQL con multi-tenant via organization_id en todas las tablas

🏢 Capa de Tenancy (Multi-coach)

organizations
id uuid PK
name text
slug text UNIQUE — mabel-alvarez
logo_url text
brand_color text
plan enum(free|pro|enterprise)
stripe_customer_id text
created_at timestamptz
profiles (extends auth.users)
id uuid PK → auth.users
organization_id uuid FK → organizations
role enum(super_admin|coach|client)
full_name text
avatar_url text
locale enum(es|en)
onboarding_completed boolean

👤 Capa de Clientes

client_profiles
id uuid PK
user_id uuid FK → profiles
organization_id uuid FK → organizations
coach_id uuid FK → profiles
occupation text
birth_year int
dependents_count int
monthly_income numeric(15,2)
monthly_expenses numeric(15,2)
status enum(lead|active|paused)
financial_diagnostics (inmutable)
id uuid PK
client_id uuid FK → client_profiles
organization_id uuid FK
total_assets numeric(15,2)
liquid_assets numeric(15,2)
total_debts numeric(15,2)
net_worth numeric(15,2)
has_health_insurance boolean
has_pension boolean
primary_goal text
recorded_at timestamptz

💰 Capa Financiera (Las 4 Cuentas)

financial_accounts
id uuid PK
client_id uuid FK
organization_id uuid FK
account_type enum:
— imprevisto (1 mes salario)
— oxígeno (6 meses)
— retiro (seguro vida)
— inversiones
target_amount numeric(15,2)
current_amount numeric(15,2)
institution text
account_snapshots (historial mensual)
id uuid PK
account_id uuid FK
organization_id uuid FK
amount numeric(15,2)
progress_pct numeric(5,2)
notes text
snapshot_month date (día 1)

-- goals
goals → tabla separada
sessions → tabla separada

🔒 Seguridad: RLS Pattern

-- Política en TODAS las tablas de datos:
CREATE POLICY "org_isolation" ON financial_accounts
  USING (organization_id = get_my_org_id());

-- Coach solo ve sus clientes:
CREATE POLICY "coach_clients" ON client_profiles
  USING (coach_id = auth.uid() OR role = 'super_admin');
